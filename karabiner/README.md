# Karabiner-Elements

Конфиг лежит в [`.config/karabiner/karabiner.json`](./.config/karabiner/karabiner.json) и подключается через `stow karabiner`.

Активный путь в системе:

```sh
~/.config/karabiner/karabiner.json
```

## Complex modifications

- Правый Shift в одиночку переключает раскладку напрямую `RussianWin` -> `Colemak`
- `Shift + Delete` = Forward Delete

Автоматические бэкапы Karabiner (`automatic_backups/`) в git не отслеживаются (см. корневой `.gitignore`).
