# TUIOS

Пользовательские настройки [TUIOS](https://github.com/Gaurav-Gosain/tuios), подключённые через GNU Stow. Основной конфиг: `~/Library/Application Support/tuios/config.toml`.

## Установка и обновление

Из корня репозитория:

```sh
stow tuios
```

TUIOS подхватывает большинство настроек после сохранения файла. Изменения горячих клавиш применяются при следующем подключении клиента: отсоединись сочетанием `Ctrl+A`, затем `d`, и запусти `tuios` снова. Текущую раскладку можно посмотреть командами:

```sh
tuios keybinds list
tuios keybinds list-custom
tuios keybinds doctor
tuios keybinds explain n
```

## Как читать сочетания

- `Ctrl+A` — лидер (prefix): нажми `Ctrl+A`, отпусти, затем нажми следующую клавишу. TUIOS перехватывает это сочетание, поэтому в оболочке `Ctrl+A` больше не переходит в начало строки.
- `Alt` и `Opt` — клавиша Option на Mac; в конфиге может встречаться написание `opt+`.
- Заглавная буква как сочетание означает `Shift`: `N` = `Shift+n`.
- Стрелки оставлены там, где они полезны как запасной вариант.

## Навигация Colemak

В раскладке Colemak буквы `h n e i` находятся на физических клавишах QWERTY `H J K L`.

| Действие | Клавиши |
| --- | --- |
| Прикрепить влево / вправо | `h` / `i` |
| Фокус вверх / вниз | `e` / `n` или `↓` |
| Предварительно выбрать направление следующего окна | `Opt+h`, `Opt+e`, `Opt+i`, `Opt+n` |
| Переместить окно влево / вправо / вверх / вниз | `Shift+h`, `Shift+i`, `Shift+e`, `Ctrl+↓` |

`n` используется для движения вниз по Colemak; новое окно создаётся клавишей `k` (или `Ctrl+n`). `N` остаётся сочетанием для новой сессии.

## Окна и режимы

В оконном режиме TUIOS управляет окнами, раскладкой и рабочими пространствами. Для ввода в терминал перейди в терминальный режим клавишей `Enter`.

| Действие | Клавиши |
| --- | --- |
| Новое окно | `k`, `Ctrl+n` или `Ctrl+A`, `c` |
| Новая сессия | `N` |
| Закрыть окно | `w` или `x`; через лидер — `Ctrl+A`, `x` |
| Переименовать окно | `r` |
| Скопировать выделенное в буфер | `c` |
| Переключить Spotlight | `b` |
| Свернуть окно | `m`; вернуть все свёрнутые — `M` |
| Перейти к окну 1–9 | `1`–`9` |
| Запустить заставку | `S` |
| Следующее / предыдущее окно | `Tab` / `Shift+Tab` |
| Увеличить окно / вернуть размер | `z` |
| Войти в терминальный режим | `Enter` |
| Вернуться в оконный режим из терминала | `Opt+Esc` |
| Открыть настройки | `,` |
| Показать справку | `?` |
| Выйти из TUIOS | `q` |

## Раскладка окон

| Действие | Клавиши |
| --- | --- |
| Прикрепить окно к левому / правому краю | `h` / `i` |
| Переставить окно влево / вправо / вверх / вниз | `Shift+h` / `Shift+i` / `Shift+e` / `Ctrl+↓` |
| Выбрать место для следующего окна | `Opt+h`, `Opt+i`, `Opt+e`, `Opt+n` |
| Разделить горизонтально / вертикально | `-` / `|` или `\` |
| Включить / выключить тайлинг | `t` или `Ctrl+A`, `Space` |
| Развернуть на весь экран / открепить | `f` / `u` |
| Повернуть разделение | `R` или `Ctrl+A`, `R` |
| Сбалансировать разделения | `Ctrl+A`, `=` |
| Увеличить / уменьшить высоту | `}` / `{` |
| Увеличить / уменьшить ширину главного окна | `>` / `<` |

Для перестановки окон в любых направлениях доступны также `Ctrl+←`, `Ctrl+→`, `Ctrl+↑` и `Ctrl+↓`.

## Развернуть и открыть окно рядом

Если окно развёрнуто полностью (`f`) или в zoom (`z`), сначала верни его в тайлинг:

1. `f` — выйти из fullscreen, если использовался `snap_fullscreen`.
2. `z` — выключить zoom, если окно было развёрнуто через zoom.
3. Создай соседнее окно: `-` — сверху/снизу, `|` или `\` — слева/справа. Через лидер: `Ctrl+A`, затем `-` или `|`.

Если новое окно нужно именно слева или сверху, сначала выбери направление через `Opt+h` или `Opt+e` (preselect), затем создай окно: `k` в оконном режиме или `Ctrl+A`, `c`.

Пока окно в zoom, новая панель получает этот же zoom и остаётся единственной видимой. Поэтому для двух видимых панелей zoom нужно выключить до split.

| Помощь / выйти из TUIOS | `?` / `q` |
| Режим выделения | `[` |
| Открыть прокрутку истории | `s` |
| Фокус между окнами по Colemak | `h` / `n` / `e` / `i` |
| Следующее / предыдущее окно | `Tab` / `Shift+Tab` |

## Боковая панель

Сначала сфокусируй панель клавишей `s` (в оконном режиме), сочетанием `Ctrl+A`, `E` или открой её через `Ctrl+A`, `b`.

| Действие | Клавиши |
| --- | --- |
| Вверх / вниз по списку | `e` или `↑` / `n` или `↓` |
| Свернуть / раскрыть раздел | `h` или `←` / `i` или `→` |
| Первый / последний элемент | `g` / `G` |
| Перейти к разделу | `Tab` / `Shift+Tab` |
| Перейти к элементу 1–9 | `1`–`9` |
| Открыть выбранное | `Enter` |
| Поиск в панели | `/` |
| Меню элемента / переименовать | `m` / `r` |
| Закрыть панель | `Esc` или `s` |

В файловом разделе: `y` — копировать, `x` — вырезать, `p` — вставить, `a` — создать, `d` — удалить в корзину, `D` — удалить навсегда, `r` — переименовать.

В разделе агентов: `x` — отменить задачу в очереди, `r` — ответить, `v` — открыть ревью, `z` — отложить, `u` — отметить непрочитанным.

## Inbox и Mail

| Действие | Inbox | Mail |
| --- | --- | --- |
| Следующий / предыдущий элемент | `n` или `↓` / `e` или `↑` | `n` или `↓` / `e` или `↑` |
| Открыть выбранное | `Enter` | `Enter` |
| Ответить | `r` | `r` |
| Закрыть | `Esc` или `q` | `Esc` или `q` |
| Фильтр / поиск | `f` | — |
| Просмотр запроса без закрытия | `Space` | — |
| Одобрить / отклонить | в просмотре: `a` / `d` | — |
| Отклонить с причиной | `N` | — |
| Отложить / отменить откладывание | `z` / `u` | — |
| Создать сообщение агенту | — | `N` |
| Переключить панель Mail | — | `o` |

В Inbox: `p` передаёт запрос дальше, `y` возобновляет задачу, `v` открывает ревью, `d` скрывает запрос, `S` показывает отложенные. `g` и `G` переходят к первому и последнему элементу списка.
