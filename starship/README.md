# starship

Конфиг лежит в [`.config/starship.toml`](./.config/starship.toml) и подключается через `stow starship`.

Активный путь в системе:

```sh
~/.config/starship.toml
```

## Что настроено

- кастомные символы для модулей (aws, buf, c, conda, dart и остальные)
- настройка раскладки и палитры — прямо в `starship.toml`
