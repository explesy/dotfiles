# Kanata

Конфиг лежит в [`.config/kanata/kanata.kbd`](./.config/kanata/kanata.kbd) и подключается через `stow kanata`.

Активный путь в системе:

```sh
~/.config/kanata/kanata.kbd
```

## Правила

- `caps` ↔ `escape` (обе клавиатуры)
- `fn` → `lctl` (только встроенная клавиатура Apple — AULA не шлёт fn)
- `right_shift` tap → `caps_lock` (переключение языка)
- `shift + backspace` → forward delete

Список устройств (хаши) закомментирован в шапке конфига.
