# mpv

Конфиг лежит в [`.config/mpv/`](./.config/mpv) и подключается через `stow mpv`.

Активный путь в системе:

```sh
~/.config/mpv/
```

## Что настроено

- языки аудио/субтитров: eng/en/rus/ru, авто-подбор субтитров по именам файлов
- скриншоты в `~/Pictures/mpv/` в PNG
- запоминание позиции (`save-position-on-quit`, watch-later)
- горячие клавиши: `a`/`r`/`R` — переключение аудио- и субтитр-дорожек (в `input.conf`)
- скрипты в `scripts/`: cycle через существующие дорожки, скрытие/показ OSC по хоткею
