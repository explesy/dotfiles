# Ranger

Конфиг лежит в [`.config/ranger/`](./.config/ranger) и подключается через `stow ranger`.

Активный путь в системе:

```sh
~/.config/ranger/
```

## Что настроено

- навигация в Colemak-стиле: `e` вверх, `n` вниз, `h` влево, `i` вправо (в `rc.conf`)
- превью файлов через `scope.sh` (текст, изображения, PDF и т.д.)
- открытие файлов по внешним программам через `rifle.conf`
