# Herdr — Terminal Workspace Manager for AI Coding Agents

Конфигурация лежит в [`.config/herdr/config.toml`](./.config/herdr/config.toml) и подключается через `stow herdr`.

Активный путь в системе:

```sh
~/.config/herdr/config.toml
```

---

## 🧭 Что такое Herdr

**Herdr** — это современный терминальный мультиплексор и воркспейс-менеджер, созданный специально для параллельной работы с AI-агентами (Codex, OpenCode, Claude Code, Cursor, Hermes и др.).

В отличие от традиционных мультиплексоров (tmux, zellij):
- **Agent-Aware:** отслеживает состояние запущенных в панелях AI-агентов (`working`, `blocked` (ждёт ответа пользователя), `done`, `idle`) и отображает их статус в боковой панели (sidebar).
- **Mouse-First UI:** полный графический контроль мышью из коробки (клики по табам/панелям, drag границ сплитов, правый клик с контекстным меню, выделение текста с авто-копированием).
- **Socket API & Богатый CLI:** позволяет скриптам и самим агентам программно создавать панели, запускать задачи в фоне без перехвата фокуса и читать вывод.
- **Git Worktree First-class:** нативная поддержка быстрого создания и переключения изолированных Git-ворктри под каждую задачу.

## 🚀 Быстрый старт и жизненный цикл сессий

### Подключение через GNU Stow

```sh
# Из корня репозитория dotfiles:
stow herdr

# Проверить статус конфигурации
herdr config check
```

### Запуск и управление сервером

Herdr работает по клиент-серверной архитектуре (как tmux). Процессы в панелях живут независимо от окна терминала или SSH-подключения.

| Действие | Команда / Клавиши | Описание |
| :--- | :--- | :--- |
| **Запуск / Аттач** | `herdr` | Подключиться к дефолтной постоянной сессии |
| **Именованная сессия** | `herdr --session <name>` | Запустить или подключиться к отдельной сессии |
| **Отсоединиться (Detach)** | `prefix + q` | Безопасно выйти из интерфейса, оставив все задачи работать в фоне |
| **Перезагрузить конфиг** | `herdr server reload-config` *(или `prefix + Shift + r`)* | Применить правки из `config.toml` на лету |
| **Проверить статус** | `herdr status` | Показать версии клиента, запущенного сервера и сокета |
| **Остановить сервер** | `herdr server stop` | Завершить сервер Herdr и закрыть все запущенные процессы |

> [!TIP]
> Закрытие окна эмулятора терминала равносильно выполнению **Detach** (`prefix + q`): сервер и фоновые процессы не пострадают.

## 🖱️ Управление мышью (Mouse-First)

Интерфейс оптимизирован для работы без необходимости заучивать шорткаты:
- **Фокус:** клик по любой панели или вкладке делает её активной.
- **Изменение размеров (Resize):** наведите курсор на границу между сплитами и перетащите её.
- **Контекстное меню:** правый клик по панели открывает меню сплитов, смены имени, зума и закрытия.
- **Копирование:** выделение любого текста мышью автоматически копирует его в системный буфер обмена (`copy_on_select = true`).

## ⌨️ Горячие клавиши (Keyboard Controls)

Префиксная клавиша в конфигурации настроена на **`Ctrl + a`** (как в tmux; нажать `Ctrl + a`, отпустить, затем нажать клавишу действия).

### Основные действия

| Сочетание | Действие |
| :--- | :--- |
| `prefix + ?` | **Справка:** интерактивный список всех доступных хоткеев |
| `prefix + b` | **Sidebar:** скрыть / показать боковую панель |
| `prefix + z` | **Zoom:** развернуть текущую панель на весь экран (повтор — вернуть) |
| `prefix + s` | **Настройки:** открыть меню настроек Herdr |
| `prefix + w` | **Воркспейсы:** открыть интерактивный переключатель воркспейсов |
| `prefix + Shift + n` | **Новый воркспейс:** создать новый рабочий воркспейс |
| `prefix + Shift + g` | **Git Worktree:** создать и открыть новый worktree воркспейс |
| `prefix + q` | **Detach:** отсоединиться от сессии |

### Управление панелями (Panes)

| Сочетание | Действие |
| :--- | :--- |
| `prefix + v` | Разделить панель **вертикально** (сплит справа) |
| `prefix + -` | Разделить панель **горизонтально** (сплит снизу) |
| `prefix + x` | Закрыть текущую панель |
| `prefix + Tab` | Переключить фокус на следующую панель |
| `prefix + Shift + p` | Переименовать панель |
| `prefix + e` | Просмотр истории вывода панели (scrollback mode) |
| `prefix + h / j / k / l` | Фокус соседней панели (влево / вниз / вверх / вправо) |

### Управление вкладками (Tabs)

| Сочетание | Действие |
| :--- | :--- |
| `prefix + c` | Создать новую вкладку |
| `prefix + 1..9` | Быстрый переход на вкладку с номером 1..9 |
| `prefix + n` | Следующая вкладка |
| `prefix + p` | Предыдущая вкладка |
| `prefix + Shift + t` | Переименовать текущую вкладку |
| `prefix + Shift + x` | Закрыть текущую вкладку |

> [!NOTE]
> **Для пользователей раскладки Colemak (`h/n/e/i`):**  
> В файле [`.config/herdr/config.toml`](./.config/herdr/config.toml) в секции `[keys]` подготовлен блок для Colemak-навигации:
> ```toml
> focus_pane_left = "prefix+h"
> focus_pane_down = "prefix+n"
> focus_pane_up = "prefix+e"
> focus_pane_right = "prefix+i"
> next_tab = "prefix+l"
> ```
> Раскомментируйте его, если хотите навигироваться по панелям через `h/n/e/i`.

## 🛠️ Управление через CLI (Socket API)

Herdr предоставляет мощный CLI-интерфейс, позволяющий управлять мультиплексором из командной строки, терминальных скриптов и AI-агентов.

### 1. Управление панелями (`herdr pane`)

```sh
# Список всех панелей в текущем сеансе
herdr pane list

# Получить ID и информацию о текущей панели
herdr pane current

# Сплит панели справа с сохранением текущего каталога без перехвата фокуса:
herdr pane split --current --direction right --cwd "$PWD" --no-focus

# Выполнить команду в указанной панели
herdr pane run <PANE_ID> "cargo test"

# Прочитать последние 100 строк вывода панели (без переносов soft-wrap)
herdr pane read <PANE_ID> --source recent-unwrapped --lines 100

# Дождаться завершения команды или появления текста в выводе
herdr pane wait-output <PANE_ID> --match "Finished" --timeout 60000

# Закрыть панель
herdr pane close <PANE_ID>
```

### 2. Управление AI-агентами (`herdr agent`)

```sh
# Список обнаруженных агентов и их статусы (working / blocked / done / idle)
herdr agent list

# Запустить агента в свободной панели
herdr agent start reviewer --kind codex --pane <PANE_ID>

# Отправить промпт агенту и дождаться завершения (settled state: idle / done / blocked)
herdr agent prompt reviewer "Проведи ревью последних изменений в git" --wait

# Дождаться, пока агент запросит ввод пользователя (blocked)
herdr agent wait reviewer --until blocked --timeout 120000

# Отправить управляющие клавиши агенту
herdr agent send-keys reviewer ctrl+c
herdr agent send-keys reviewer esc

# Прочитать контекст вывода агента
herdr agent read reviewer --lines 80
```

### 3. Управление воркспейсами и Git Worktrees (`herdr workspace` & `herdr worktree`)

```sh
# Список воркспейсов
herdr workspace list

# Создать новый воркспейс для проекта
herdr workspace create my-feature --cwd ~/projects/my-repo

# Переключиться на воркспейс
herdr workspace focus <WORKSPACE_ID>

# Создать изолированный Git Worktree воркспейс
herdr worktree create feature/login ~/worktrees/feature-login

# Закрыть воркспейс
herdr workspace close <WORKSPACE_ID>
```

## 🤖 Интеграция с AI-стеком

Herdr интегрируется с агентными инструментами через скрипты-хуки (lifecycle hooks). При изменении состояния агента (начало генерации, запрос подтверждения, завершение задачи) хук мгновенно отправляет событие в сокет Herdr:

- `working` — агент генерирует код или выполняет команды (активная фаза).
- `blocked` — агент ожидает одобрения инструмента или ответа пользователя (требует внимания!).
- `done` — задача успешно выполнена.
- `idle` — ожидание новой задачи.

### Проверка и установка интеграций

```sh
# Проверить статус установленных хуков для всех поддерживаемых агентов:
herdr integration status

# Установить интеграцию (например, для Codex, OpenCode, Claude, Cursor):
herdr integration install codex
herdr integration install opencode
herdr integration install claude
herdr integration install cursor
```

### Доступные интеграции в системе:
- **Codex:** хук `~/.codex/herdr-agent-state.sh`, подключен через `~/.codex/hooks.json`.
- **OpenCode:** плагины `plugins/herdr-agent-state.js` и `herdr-tui-session.js`.
- **Claude Code:** хук `~/.claude/hooks/herdr-agent-state.sh`.
- **Cursor:** хук `~/.cursor/herdr-agent-state.sh`.
- **Hermes:** плагин `~/.hermes/plugins/herdr-agent-state`.

## ⚙️ Настройки в `config.toml`

Основные параметры, вынесенные в `dotfiles`:

```toml
onboarding = false                 # Отключение начального онбординга

[terminal]
default_shell = "/opt/homebrew/bin/fish" # Шелл по умолчанию для новых панелей
new_cwd = "follow"                # Наследование CWD текущей панели

[ui]
status_indicators = "symbols"     # Индикаторы агентов значками
mouse_capture = true              # Полноценная поддержка мыши
copy_on_select = true             # Автокопирование текста при выделении
pane_borders = "auto"             # Рамки вокруг панелей
pane_gaps = true                  # Визуальный отступ между сплитами

[ui.toast]
delivery = "herdr"                # Всплывающие тост-уведомления от фоновых агентов

[keys]
prefix = "ctrl+a"                 # Префиксная клавиша
```
