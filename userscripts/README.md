# userscripts

Скрипты для браузерных расширений (Violentmonkey / Tampermonkey).

- [metube-youtube.user.js](./metube-youtube.user.js) — кнопка отправки YouTube-видео в MeTube одним кликом
  - хост MeTube зашит через `@connect` (Tailscale)
  - без стабильности фиксов может ломаться при изменении DOM YouTube — см. историю коммитов
