# zsh

Конфиг лежит в [`.zshrc`](./.zshrc) и подключается через `stow zsh`.

Активный путь в системе:

```sh
~/.zshrc
```

## Что настроено

- базируется на manjaro-zsh-config (powerline), отключён manjaro prompt
- common-алиасы: `ls`/`exa` в стиле `eza -la --sort=type`, `tmuxn`/`tmuxa`
- исторические и прочие утилиты — прямо в `.zshrc`
